# Data definitions and recording windows

The source recordings contain long monitor histories extending beyond this experiment. The release retains only each batch's loading-metadata interval, extended **10 minutes before the analysis start** for sleep-bout annotation. The stop is the metadata stop, inclusive; it is not shortened to an arbitrary six-day cutoff. The phenotype code subsequently selects six analysis days. Some metadata windows therefore extend beyond the phenotype window.

Rows were selected using DAM date/time columns. The complete selected lines, including their original record numbers, all 32 activity channels, and line endings, were copied verbatim. No counts, timestamps, missing intervals, or jitter were repaired or imputed. Original files were left unchanged. `data/metadata/raw_crop_manifest.tsv` gives each source hash, original and cropped sizes, requested bounds, observed first/last timestamps, row counts, and output SHA-256. Dates are recording wall-clock labels; the pipeline's UTC-style labels are not geographic timezone conversions.

Each batch folder retains the original `loadinginfo_*.csv`, `summary_*.csv`, and available `removed_list1_*.csv` / `removed_list2_*.csv`. Loading metadata maps file and channel (`region_id`) to genotype, sex, and analysis times. Original metadata labels are preserved; some historical `Light` fields contain a typographic value. The analysis code explicitly uses **8L:16D**, and the experimental conditions are 21.5°C, following group housing under 12L:12D. The recorded DGRP809 label had already been corrected to DGRP805 in the analysis source before this release.

The primary cohort reproduces the original GIGEM retention decisions from the supplied summaries and exclusion lists. The release does not replace those decisions with a newly optimized death rule. There are 9,152 planned channel records, of which 6,228 were retained (5,651 DGRP and 577 CS). 178 DGRP lines were recorded; 176 satisfy the primary eligibility rule. The retained individual IDs, exclusion categories, and coverage checks are in `reproducibility/publication_analysis/minute_rebuild/fly_qc_all_batches.csv`.

A minute with at least one beam crossing is active. Sleep requires at least five consecutive inactive minutes; shorter inactivity is not sleep. P(Wake) and P(Doze) use consecutive movement/inactivity states and do not use the five-minute sleep labels. The phenotype dictionary specifies transformations and aggregation. Sleep-change traits use the stated differences between days; D2–D6 state/profile summaries require the relevant valid days. Missing data are retained as missing.

Repeated monitor histories in the original folders are not automatically repeated observations: batch windows identify the experimental segment. The release retains all recorded channels in the selected windows, including excluded flies, so QC decisions remain inspectable. QC summaries and sensitivity analyses remain separate from the primary cohort.

`results/tables/TABLE_NOTES.md` describes the supplementary table groups. `results/source_data/` contains the actual values used to draw each figure; thinned Manhattan plotting data are not the complete association statistics. Full scans are supplied separately.
