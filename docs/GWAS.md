# GWAS inputs and outputs

The six primary traits are NightSleepChange, MovingShapePC1, NightPWake, NightPDoze, LDHarmonicR2, and TotalSleep. `reproducibility/profile_gwas_call90_maf10/inputs/` contains the numerical phenotypes, line inclusion lists, Wolbachia/inversion covariate matrices, named covariates, and the 36-run plan. `line_<number>` corresponds to the DGRP line number. FID/IID order is retained in the supplied FAM and GRM ID files.

The published DGRP release-6 genotypes were obtained from the DGRP resource described by Mackay et al. (2012) and Huang et al. (2014). The exact processed 176-line BED/BIM/FAM input is provided in `reproducibility/publication_analysis/gwas_shared/common_min8/`, with checksums in the release manifest. This avoids relying on an unversioned download to reproduce the analyzed matrix. The BIM file provides marker identifiers, alleles, and arm-specific release-6 positions. Original annotation labels refer to DGRP release 6.46; selected candidate annotations are in the results tables. This release does not include new DNA sequencing data.

The BED pool and original GRM use 2,208,124 variants with MAF at least 5%. The supplied `grm.scaled.grm.gz` and `grm.scaled.grm.id` encode the exact population-relatedness matrix used in the analysis; it was normalized to mean diagonal one. **Do not recompute this GRM using the narrower reporting mask.**

The primary reporting mask is genotype call rate at least 90% and MAF at least 10% among the 176 analyzed lines, giving 1,428,812 variants per trait. Complete `.mlma` files retain all 2,208,124 computed records; applying the mask is required before interpreting the manuscript's numbers. `shared/cohort_counts.frqx` allows independent reconstruction of this mask. The `exclude_influential` scans use their own reduced-cohort `.counts.frqx` files. The whole-chromosome LOCO scans use the same genotype bytes with recoded chromosome identifiers in `shared/whole_chromosome.bim`.

`code/export_eligible_gwas.R` applies the appropriate cohort mask, validates variant counts, minimum P values, nominal hit counts and genomic inflation against the frozen summaries, and exports complete eligible statistics as gzipped TSVs. It does not refit any model. The six primary scans yield 50 variant–trait records at P < 1e-5, representing 47 variants. This threshold is exploratory. The per-trait threshold is 0.05/1,428,812 and the six-trait threshold is 0.05/(6 × 1,428,812).

GCTA `.mlma` columns are Chr, SNP, bp, A1, A2, Freq, b, se, and p. The effect `b` and standard error are per coded A1 allele; Freq is its allele frequency, not necessarily the minor-allele frequency. PLINK count allele orientation can change in reduced cohorts; join by SNP and check alleles before interpreting allele-specific values. The export preserves the original GCTA effect direction.

All 36 complete genome-wide scans and model inputs are supplied. The selected reusable code covers rerunning these model configurations from the frozen genotype/phenotype inputs, reconstructing eligibility, and reproducing the manuscript figures/tables. It does not reimplement every exploratory annotation or candidate-diagnostic analysis. Those final diagnostic tables and their underlying published genotype/phenotype inputs are included.
